# ⛏️ 돌 캐기 3D

브라우저에서 바로 실행되는 1인칭 3D 채굴 게임입니다. (Three.js 사용, 단일 `index.html`)

## 실행
`index.html`을 브라우저로 열거나, 로컬 서버로 띄우세요.

```bash
python3 -m http.server 8000
# http://localhost:8000 접속
```

## 조작
| 키 | 동작 |
|---|---|
| WASD / 방향키 | 이동 (Shift 달리기) |
| 마우스 | 시점 회전 |
| 왼쪽 클릭 (누르고 있기) | 곡괭이 휘두르기 |
| Space | 점프 |
| B | 상점 열기/닫기 |
| T | 자율 모드 켜기/끄기 |
| Esc | 일시정지 |

모바일: 왼쪽 조이스틱으로 이동, 화면 드래그로 시점, `캐기` 버튼으로 채굴.

## 게임 규칙
- 바위를 깨면 광석이 나와 가방에 들어갑니다.
- 빨간 지붕 상점 근처에서 광석을 팔아 골드를 법니다.
- 골드로 곡괭이(나무 → 돌 → 구리 → 철 → 금 → 다이아)와 휘두르기 속도를 강화합니다.
- 단단한 광석은 일정 등급 이상의 곡괭이가 있어야 캘 수 있습니다.
- 맵 중앙 구덩이 쪽으로 갈수록 금·에메랄드·다이아몬드가 더 자주 나옵니다.
- 진행 상황은 브라우저에 자동 저장됩니다.

| 광석 | 가치 | 필요 곡괭이 |
|---|---|---|
| 돌 | 1G | 나무 |
| 석탄 | 4G | 나무 |
| 구리 | 10G | 돌 |
| 철 | 25G | 구리 |
| 금 | 70G | 철 |
| 에메랄드 | 160G | 금 |
| 다이아몬드 | 400G | 다이아 |

## 🤖 자율 모드
`T` 키나 화면 왼쪽 위 버튼을 누르면 자율 모드가 켜집니다.
- 지금 곡괭이로 캘 수 있는 바위 중에서 가깝고 값진 것을 골라 걸어가서 캡니다.
- 가방이 25개 차면 상점으로 가서 팔고, 곡괭이 강화를 먼저 산 다음 남은 돈으로 속도를 강화합니다.
- 길이 막히면 점프하거나 다른 바위로 목표를 바꿉니다.
- 이동 키(WASD)나 조이스틱을 움직이면 자율 모드가 꺼지고 직접 조작으로 돌아옵니다.
