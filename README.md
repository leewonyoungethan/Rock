# ⛏️ 곡괭이 봉우리

블록으로 된 거대한 산을 한 칸씩 파고 들어가는 1인칭 3D 채굴 게임입니다. (Three.js, 단일 `index.html`)

## 실행
`index.html`을 브라우저로 열거나 로컬 서버로 띄우세요.

```bash
python3 -m http.server 8000
# http://localhost:8000 접속
```

## 조작
| 키 | 동작 |
|---|---|
| WASD / 방향키 | 이동 (Shift 달리기, 한 칸 높이는 자동으로 올라섬) |
| 마우스 움직이기 | 시점 회전 (클릭 없이도 동작) |
| 커서를 화면 왼쪽/오른쪽 끝에 두기 | 그쪽으로 계속 회전 |
| 오른쪽 버튼 (누르고 있기) | 앞으로 걷기 — 마우스만으로도 플레이 가능 |
| 왼쪽 클릭 (누르고 있기) | 블록 캐기 |
| Space | 점프 |
| B | 상점 열기/닫기 |
| T | 자율 모드 켜기/끄기 |
| R | 순위 보기 |
| P | 펫 창 열기 |
| Enter | 코드 입력창 열기 |
| Esc | 일시정지 |

모바일: 왼쪽 조이스틱 이동, 화면 드래그로 시점, `캐기`·`점프`·`상점` 버튼.

## 게임 규칙
- 산은 약 20,000개의 블록으로 되어 있습니다 (가로세로 53칸, 높이 32칸). 겉은 잔디·흙, 그 아래는 돌, 산 한가운데 아래쪽 심장부는 단단한 심층암입니다.
- 표면에서 깊이 들어갈수록, 그리고 심장부에 가까울수록 귀한 광맥이 나옵니다. 금·에메랄드·다이아몬드 광맥은 반짝입니다.
- 캔 블록은 광물이 되어 가방에 들어갑니다. 가방이 가득 차면 더 캘 수 없으니 산기슭 상점에서 파세요.
- 상점에서 곡괭이(나무 → 돌 → 구리 → 철 → 금 → 다이아), 가방 크기, 휘두르기 속도를 강화합니다.
- 산을 90% 이상 캐면 새 산이 솟아오릅니다. 상점에서 직접 새 산을 만들 수도 있습니다.
- 진행 상황과 파낸 산의 모양은 브라우저에 자동 저장됩니다.

| 블록 | 광물 가치 | 필요 곡괭이 |
|---|---|---|
| 잔디 / 흙 | 1G | 나무 |
| 돌 | 2G | 나무 |
| 석탄 광맥 | 6G | 나무 |
| 심층암 | 5G | 돌 |
| 구리 광맥 | 12G | 돌 |
| 철 광맥 | 28G | 구리 |
| 금 광맥 | 70G | 철 |
| 에메랄드 광맥 | 160G | 금 |
| 다이아몬드 광맥 | 400G | 다이아 |

## 🤖 자율 모드
`T` 키나 화면 왼쪽 위 버튼으로 켭니다.
- 지금 곡괭이로 캘 수 있는 드러난 블록 중 가장 가까운 것부터 캡니다. 길을 막는 블록은 파면서 지나갑니다.
- 가방이 차면 상점으로 가서 팔고, 곡괭이 → 가방 → 속도 순으로 강화합니다.
- 이동 키(WASD)나 조이스틱을 움직이면 꺼집니다.

## 🔑 코드
`Enter` 키나 `🔑 코드` 버튼으로 입력창을 엽니다.
- **방탄유리**: 이동 속도가 100배 빨라집니다(자율 모드에도 적용). 한 번 더 입력하면 꺼집니다.

## 🏆 순위
`R` 키나 `🏆 순위` 버튼으로 엽니다. 상점에서 번 골드 합계 순으로 상위 50명을 보여 줍니다.
- claude.ai 아티팩트로 열었을 때만 동작합니다. 광물을 팔 때마다 내 기록이 올라갑니다.
- 기록을 올리려면 아티팩트 공유 설정에서 참여자(Contributor) 이상 권한이 필요합니다. 뷰어는 순위를 보기만 할 수 있습니다.

## 🐾 펫
`P` 키나 `🐾 펫` 버튼으로 엽니다. 알을 부화시켜 펫을 얻고, 최대 3마리까지 데리고 다니면 능력이 모두 더해집니다.
- 🥚 산 알 150G (희귀 이상 12%), 🌟 황금 알 1,500G (희귀 이상 60%)
- 데리고 다니는 펫은 블록 모양 동물로 내 옆을 따라다닙니다. 날개 달린 펫은 날아다닙니다.
- 필요 없는 펫은 놓아주면 등급에 따라 골드를 받습니다 (최대 30마리 보관).

| 펫 | 등급 | 능력 |
|---|---|---|
| 굴착 두더지 | 일반 | 채굴 피해 +15% |
| 도토리 다람쥐 | 일반 | 판매가 +10% |
| 조약돌 달팽이 | 일반 | 가방 +10칸 |
| 동굴 박쥐 | 희귀 | 이동 속도 +15% |
| 광맥 여우 | 희귀 | 판매가 +25% |
| 바위 거북 | 영웅 | 가방 +30칸 |
| 수정 골렘 | 영웅 | 채굴 피해 +45% |
| 용암 드래곤 | 전설 | 피해 +30%, 4초마다 근처 블록을 스스로 캠 |
| 별빛 부엉이 | 전설 | 판매가 +60%, 이동 속도 +20% |

# 🦊 여우의 달걀 도둑 (`eggsteal.html`)

농장의 새들이 둥지에서 **알을 품은 채 자고** 있습니다. 💤
알을 훔치는 순간 둥지 주인이 **깨어나서 쫓아옵니다.** 훔친 알을 왼쪽 아래 여우 굴까지 가져가세요. (Three.js, 단일 파일)

## 조작
| 키 | 동작 |
|---|---|
| WASD / 방향키 | 이동 |
| Shift | 살금살금 (느리지만 훔칠 때 새가 늦게 깸) |
| E / Space 꾹 | 둥지에서 알 훔치기 · 할당량 달성 후 굴에서 귀가 |
| P / Esc | 일시정지 |

모바일: 왼쪽 조이스틱 이동, `훔치기` 버튼(꾹), `살금` 토글.

## 규칙
- 알을 하나 훔칠 때마다 그 둥지 주인이 깨어나 추격합니다. 같은 둥지에서 더 훔치려면 주인을 멀리 유인한 뒤 돌아와야 해요.
- 따돌리는 방법: **덤불에 숨기**, **둥지에서 추격 거리 밖으로 도망**, **울타리 밖으로 나가기**. 포기한 새는 둥지로 돌아가 다시 잠듭니다.
- 잡히면 들고 있던 알은 원래 둥지로 돌아가고 목숨이 하나 줄어듭니다 (3개).
- 알은 최대 5개까지 들 수 있고, 하나 들 때마다 7%씩 느려집니다.
- 동이 트기 전까지 할당량을 채우면 다음 밤으로. 밤이 지날수록 빠른 새가 늘어납니다 (밤 2부터 칠면조·타조 등장).

## 추천 속도 (밸런스 표)
단위: 속도 = 칸/초, 회전 = 라디안/초. 값은 `eggsteal.html` 맨 위 `FOX`, `TYPES`에서 바로 고칠 수 있습니다.

| 캐릭터 | 속도 | 회전 | 깨는 시간 (살금살금) | 추격 거리 | 알 점수 | 알 개수 |
|---|---|---|---|---|---|---|
| 🦊 여우 (나) | 6.4 (살금 3.0) | 즉시 | - | - | - | 최대 5개 들기 |
| 🐔 암탉 | 4.2 | 8.0 | 0.45초 (1.0초) | 10칸 | 1점 | 3 |
| 🪿 거위 | 5.6 | 6.0 | 0.3초 (0.8초) | 15칸 | 2점 | 2 |
| 🦃 칠면조 | 6.2 | 4.5 | 0.6초 (1.3초) | 14칸 | 3점 | 2 |
| 🐦 타조 | 7.6 | 2.2 | 0.8초 (1.6초) | 22칸 | 6점 (황금알) | 1 |

여우가 알을 든 개수별 속도: 0개 6.4 · 1개 5.95 · 2개 5.5 · 3개 5.06 · 4개 4.61 · 5개 4.16

설계 의도:
- **암탉**: 알 1개만 든 여우보다 확실히 느림 → 입문용.
- **거위**: 가장 빨리 깸. 알 2개까지는 여우가 더 빠르지만, 3개부터는 따라잡힘.
- **칠면조**: 알을 든 여우보다 빠름. 대신 회전이 느려서 장애물을 끼고 돌거나 덤불로 따돌려야 함.
- **타조**: 직선에서는 절대 못 이김 (7.6). 회전이 매우 느려(2.2) 급하게 꺾으면 크게 헛돌기 때문에 지그재그로 피해야 함. 황금알 6점.
- 새는 목표 방향과 몸 방향이 어긋날수록 감속하므로, 회전 값이 곧 "따돌리기 쉬운 정도"입니다.
