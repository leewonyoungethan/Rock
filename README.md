# ⛏️ 돌 캐기 3D

브라우저에서 바로 실행되는 1인칭 3D 채굴 게임입니다. (Three.js 사용, 단일 `index.html`)

## 실행
`index.html`을 브라우저로 열거나, 로컬 서버로 띄우세요.

```bash
python3 -m http.server 8000
# http://localhost:8000 접속
```

## 조작
| 키 | 동작 |
|---|---|
| WASD / 방향키 | 이동 (Shift 달리기) |
| 마우스 | 시점 회전 |
| 왼쪽 클릭 (누르고 있기) | 곡괭이 휘두르기 |
| Space | 점프 |
| B | 상점 열기/닫기 |
| Esc | 일시정지 |

모바일: 왼쪽 조이스틱으로 이동, 화면 드래그로 시점, `캐기` 버튼으로 채굴.

## 게임 규칙
- 바위를 깨면 광석이 나와 가방에 들어갑니다.
- 빨간 지붕 상점 근처에서 광석을 팔아 골드를 법니다.
- 골드로 곡괭이(나무 → 돌 → 구리 → 철 → 금 → 다이아)와 휘두르기 속도를 강화합니다.
- 단단한 광석은 일정 등급 이상의 곡괭이가 있어야 캘 수 있습니다.
- 맵 중앙 구덩이 쪽으로 갈수록 금·에메랄드·다이아몬드가 더 자주 나옵니다.
- 진행 상황은 브라우저에 자동 저장됩니다.

| 광석 | 가치 | 필요 곡괭이 |
|---|---|---|
| 돌 | 1G | 나무 |
| 석탄 | 4G | 나무 |
| 구리 | 10G | 돌 |
| 철 | 25G | 구리 |
| 금 | 70G | 철 |
| 에메랄드 | 160G | 금 |
| 다이아몬드 | 400G | 다이아 |

# 🦊 여우의 달걀 도둑 (`eggsteal.html`)

한밤중 농장에 몰래 들어가 계란을 훔치는 3D 잠입 게임입니다. (Three.js, 단일 파일)

## 조작
| 키 | 동작 |
|---|---|
| WASD / 방향키 | 이동 |
| Shift | 살금살금 (느리지만 닭이 못 듣고, 덜 들킴) |
| E / Space 꾹 | 둥지에서 계란 줍기 · 할당량 달성 후 굴에서 귀가 |
| P / Esc | 일시정지 |

모바일: 왼쪽 조이스틱 이동, `줍기` 버튼(꾹), `살금` 토글.

## 규칙
- 닭장 앞 둥지에서 계란을 주워 **왼쪽 아래 여우 굴**로 가져가면 점수가 됩니다. (황금알 ✨ = 5점)
- 계란은 최대 5개까지 들 수 있고, 많이 들수록 느려집니다.
- 농부의 손전등 시야(노란 부채꼴)에 오래 있으면 **?** → **!** 로 추격이 시작됩니다. 닭장·헛간 뒤에 숨으면 시야가 막혀요.
- 덤불 안에서 멈추거나 살금살금 움직이면 보이지 않습니다.
- 뛰어다니거나 그냥 계란을 집으면 근처 닭이 "꼬꼬댁!" 울어 농부를 부릅니다.
- 잡히면 들고 있던 계란을 잃고 목숨이 줄어듭니다 (3개). 농부는 울타리 밖으로 나오지 않아요.
- 동이 트기 전(타이머)까지 할당량을 채우면 다음 밤으로. 밤이 지날수록 농부가 늘고 새벽이 가까워지면 시야가 넓어집니다.
- 할당량을 일찍 채우고 굴에서 귀가하면 남은 시간 보너스를 받습니다.
